# Roadmap

- **v0.1.0 / Loop 1:** bootstrap, schema e instalação segura.
- **v0.1.1 / Loop 2:** aba Procedimentos no chamado, inicialmente vazia.
- **v0.2.0 / Loops 3–4:** CRUD de procedimentos e etapas.
- **Loop atual:** checklist manual básico no Ticket, com progresso e auditoria de conclusão.
- **Loops 5–8:** serviço de associação, checklist avançado e auditoria completa.
- **v0.3.0+:** regras automáticas usando o mesmo serviço de associação.
- **v1.0.0:** consolidação, testes, segurança, migrações e UX nativa.
